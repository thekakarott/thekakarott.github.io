## Features 📋

⚡️ **Cyberpunk / Terminal Aesthetic**: Futuristic dark layout with neon accents and glowing UI boxes.
⚡️ **Holographic Avatar**: Animated 3D orbit scanning avatar container.
⚡️ **Interactive Diagnostics Chatbot Widget**: Virtual console chatbot simulator supporting commands `/about`, `/skills`, `/projects`, `/clear` or `/help`.
⚡️ **Neural Canvas Particles**: Active background particle network dynamically interacting with mouse movements.
⚡️ **3D Card Hover Tilt**: Multi-axis perspective rotation and tracklight shine on technical cards.
⚡️ **Fully Mobile Friendly**: Responsive slide-out navigation menu and touch interface pointer coarse cursor suppression.

## Sections 📚

✔️ **Home**: Typed terminal greeting and primary core links.\
✔️ **About**: Personal profile summaries, publication statistics, and avatar interface.\
✔️ **Diagnostics**: Command-line interactive terminal simulator.\
✔️ **Timeline**: Chronological education and industry experience history.\
✔️ **Publications**: Scanned grid containing clickable IEEE, Springer, and ScienceDirect papers.\
✔️ **Modules / Projects**: Highlighted computer vision, deep learning, and audio synthesis project cards.\
✔️ **Contact Node**: Transmission dispatch form and LinkedIn secure connect handshake link.
